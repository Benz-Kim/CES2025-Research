# Contributing

Contributions should improve evidence or challenge a conclusion.

For a source addition, record its issuer, exact URL, publication date, retrieval date, evidence type and the narrow claim it supports in [the register](sources/REGISTER.md). Mark company-controlled claims explicitly. Do not use a later source to rewrite what was knowable at the event date.

For an analytical change, state the old conclusion, new evidence, revised conclusion and remaining uncertainty. Update linked research notes and the README when the top-level thesis changes.

For an experiment, follow [the validation design](research/04_VALIDATION_DESIGN.md), publish configuration and raw observations, and retain failed runs. Proposed tests must remain labeled as proposed until executed.

Use English for Markdown. Prefer one commit per coherent evidential or analytical change. Commit messages should describe the work performed; preserve actual dates and contribution boundaries. Do not inflate the appearance of a longitudinal project by backdating or manufacturing intermediate states.

Do not upload third-party papers, paid reports, confidential material or personal application records. Link to original publications and respect their terms. No repository-wide license is currently granted; linked sources retain their own terms.
